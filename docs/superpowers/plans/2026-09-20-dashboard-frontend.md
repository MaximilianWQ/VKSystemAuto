# Дашборд оператора, фронтенд — план

**Goal:** PWA оператора: вход по passkey, очередь диалогов, переписка с вложениями, статистика, настройки. Устанавливается на экран «Домой» на iOS, принимает пуши.

**Spec:** `docs/superpowers/specs/2026-09-20-vk-support-bot-design.md`
**Серверная часть:** `docs/superpowers/plans/2026-09-20-dashboard-backend.md` — выполнена.

Примечание о форме: здесь нет построчного кода, в отличие от планов серверной
части. Причина — фронтенд реализуется в этой же сессии, и дублировать две тысячи
строк React сначала в план, а потом в файлы бессмысленно. Вместо кода
зафиксированы архитектура, визуальные токены, поведение каждого экрана и критерии
приёмки: по ним результат проверяется так же строго.

## Стек

React 19 + TypeScript + Vite + Tailwind 4 + Motion. Сборка в статику, FastAPI
отдаёт её и делает SPA-фолбэк на всё, что не `/api`, не `/ws` и не `/vk`.

## Визуальный язык

По референсам: тёплый светло-серый фон, белые карточки с крупным радиусом и мягкой
тенью, большие градиентные плитки на числах, тонкая типографика с плотным трекингом.

| Токен | Значение |
|---|---|
| `--bg` | `#F2F1EF` тёплый светло-серый |
| `--surface` | `#FFFFFF` |
| `--text` | `#111111` |
| `--muted` | `#7A7A78` |
| `--line` | `rgba(0,0,0,.07)` |
| `--radius` | 28px карточки, 20px вложенные, 999px пилюли |
| Тень | `0 1px 2px rgba(0,0,0,.04), 0 10px 30px rgba(0,0,0,.05)` |
| Градиент «хорошо» | зелёный → лайм `#6FCF62 → #C8F169` |
| Градиент «внимание» | оранжевый → коралл `#FFA24A → #FF6B4A` |
| Градиент «нейтраль» | сиреневый → голубой `#B9A7FF → #8EC5FF` |
| Шрифт | `-apple-system, "SF Pro Text", Inter, sans-serif` |
| Числа | 44–64px, `letter-spacing: -0.03em`, `font-variant-numeric: tabular-nums` |

Анимации пружинные и короткие: появление списка лесенкой по 25 мс, переход между
диалогами через общий layout, кнопки дают отклик на нажатие. При
`prefers-reduced-motion` движение отключается.

Тёмная тема поддерживается через `prefers-color-scheme`.

## Экраны

**Вход** (`/login`). Одна кнопка «Войти по passkey». Если ключей нет, сервер
отвечает 409 — показываем инструкцию: напишите боту слово «дашборд».

**Регистрация** (`/setup?token=…`). Кнопка создаёт passkey и сразу открывает сессию.
Ошибки: протухшая ссылка, отказ браузера, отсутствие поддержки WebAuthn.

**Диалоги** (`/`). Слева очередь, справа переписка. На телефоне — стек с кнопкой
назад. В карточке очереди: аватар, имя, превью, время ожидания, счётчик
непрочитанных. Открытый диалог помечается прочитанным. В переписке: пузыри с двух
сторон, фото галереей, голосовые плеером, файлы карточкой со скачиванием, видео
превью со ссылкой на плеер ВК. Поле ввода с прикреплением файла и кнопкой
«Закрыть обращение». Реалтайм по WebSocket с переподключением.

**Статистика** (`/stats`). Четыре градиентные плитки: обращения за сутки и неделю,
среднее время первого ответа, средняя оценка.

**Настройки** (`/settings`). Список ключей passkey, переключатель пушей, кнопка
выхода, подсказка про установку на экран «Домой».

## PWA

`manifest.webmanifest` с `display: standalone`, иконки 192/512 и maskable,
`apple-touch-icon`. Service worker кеширует оболочку и показывает пуши.

Ограничения iOS заложены в интерфейс: пуши работают с 16.4+, только когда
приложение добавлено на экран «Домой», разрешение запрашивается по нажатию.
Если открыто не в standalone — вместо переключателя пушей показываем подсказку
«Поделиться → На экран Домой». Подписка обновляется при каждом запуске, потому что
iOS её периодически сбрасывает.

## Критерии приёмки

1. `npm run build` без ошибок и предупреждений TypeScript
2. `npx tsc --noEmit` чисто
3. Сборка отдаётся FastAPI, SPA-фолбэк не перехватывает `/api`, `/ws`, `/vk`
4. В реальном браузере: `/login` рисуется, показывает верное состояние при 409,
   `/stats` и `/settings` открываются, вёрстка не ломается на ширине 390px
5. `manifest.webmanifest` и service worker отдаются с правильными типами
6. Существующие 296 тестов бэкенда остаются зелёными
